Turn a Google Slides deck into numbered Arma 3 `.paa` briefing images in one click.

Paste the share link, pick your mission's `intel` folder, press the button. Every slide
is downloaded, named `in1.png`, `in2.png`, `in3.png` and so on, resized to a valid Arma
texture size and converted to `.paa` with the official Arma 3 Tools.

Edit the deck, run it again, and the images are replaced under the same names. Nothing
in the mission file has to change.

## Download

| File | What it is |
|---|---|
| **`TLB.Intel.Maker.exe`** | The GUI. Download and run, no Python and no install. Start here. |
| `intel.exe` | The same thing for the command line, for scripting or batch work. |
| `TLB-Intel-Maker-1.0.0-windows.zip` | Both of the above plus the README and `setup.bat`. |

GitHub replaces the spaces in the name with dots, so the GUI download arrives as
`TLB.Intel.Maker.exe`. It works exactly the same, rename it if the dots bother you.

`setup.bat` in the zip is optional, it just adds Desktop and Start Menu shortcuts.

Windows will warn that the file is unsigned the first time you run it. Choose
**More info, then Run anyway**. Code signing certificates cost money, and the source is
all here if you would rather build it yourself with `build.bat`.

## Requirements

- **Arma 3 Tools**, installed from Steam. TLB Intel Maker finds it automatically by
  reading your Steam library folders. If it cannot, point it at the folder yourself.
- The presentation must be shared: *Share, General access, Anyone with the link,
  Viewer*. Nothing else is needed, no Google account, no API key and no sign-in.

## Sizing your slides

Arma's engine needs texture dimensions that are powers of two, so set your Google Slides
page size to **2048 x 1024 px** before you start (**File, Page setup, Custom, Pixels**).
The tool always resizes to fit, so what this really buys you is avoiding distortion. A
default 16:9 deck gets squeezed about 11% vertically to reach 2:1.

Percent signs in paths are left alone, because Arma's *Other Profiles* folders really
are named `CPT%20W%2e%20Fosse` on disk.
